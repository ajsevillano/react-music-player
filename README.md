# React Music Player

A lo-fi music player built with React and TypeScript that streams tracks directly from [Chillhop](https://chillhop.com).

## Features

- Stream lo-fi tracks from the Chillhop catalog
- Play / pause, skip forward and backward
- Seekable progress bar with per-track color gradient
- Collapsible library sidebar
- Auto-advances to the next track on song end

## Tech Stack

| Layer | Tech |
|-------|------|
| UI | React 18 + TypeScript |
| Build | Vite 6 |
| Styles | SCSS |
| Icons | FontAwesome |
| Audio | Chillhop Streaming API |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
